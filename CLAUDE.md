## Project 
Das Projekt soll eine Weboberfläche sein, um Logs einer Suchmaschine zu Analysieren.
Dort soll der Nutzer 1-4 Kacheln erstellen können, die ein Liniendiagram mit Datenpunkten zeigt (time x metric value).
Jede Kachel soll die folgenden Einstellungsmöglichkeiten haben:
Art der Statistik: Umschalter zwischen Search count (Suchanfragen) und Sessions count (Sitzungen).
Start- und Enddatum: Datumsfelder (z. B. 01.10.2024 bis 31.10.2024).
Zeitintervall der datenpunkte: Einstellbar zwischen Täglich, Wöchentlich, Monatlich, Quartalsweise und Jährlich
Kategorie: Dropdown mit für die Sozialarbeit relevanten Bereichen (Alle Themenbereiche, Jugendhilfe, Krisenintervention, Schuldnerberatung, etc.)
Die Daten für das Frontend kommen fertig berechnet von meinem eigenen Backend das ich lokal laufen lassen werde, es nutzt FASTAPI für die API endpoints.
